# OPTRANE Command identifiers

The application uses OPTRANE consistently across the desktop package, Tauri identifier, deep links, API headers and backend runtime.

- npm package: `optrane-desktop`
- Tauri identifier: `com.optrane.command`
- deep links: `optrane://...`
- desktop API base: `VITE_OPTRANE_API_BASE`
- backend Edge Function: `optrane-api`
- ClickHouse database: `optrane`
- strict runtime flags: `OPTRANE_REQUIRE_AGENT_RUNTIME`, `OPTRANE_REQUIRE_MCP`
